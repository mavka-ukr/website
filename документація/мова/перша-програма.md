# Перша програма

Створіть файл `привіт.м`:

```мавка
поки дійсне
  оновити_кнопки() ;; оновити стан кнопок
  якщо Кнопки.б.щойно_відпущено
    перервати
  кінець

  Полотно.заповнити(Колір.ЧОРНИЙ)
  Полотно.круг(Полотно.Ш/2, Полотно.В/2, 20, Колір.БІЛИЙ)
  Полотно.відмалювати() ;; запланувати відмалювання
кінець
```

Запустіть, виконавши цю команду:

```shell
мавка привіт.м
```
