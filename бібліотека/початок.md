# Бібліотека Мавки

> НАРАЗІ НЕДОСТУПНО!

Створіть файл `привіт.м`:

```мавка
взяти біб афс

афс.записати("привітики", "./якийсь.текст", дія()
  афс.прочитати(Текст, "./якийсь.текст", дія(значення)
    друк(значення)
  кінець)
кінець)
```

Та запустіть мавку вказавши шлях до бібліотеки:

```sh
мавка -Б=./бібліотека_мавки привіт.м
```
